# Kyro Outreach

Kyro Outreach is an approval-first outreach workspace for Kcreatives.

This rebuild starts from the product requirements in the original specification: restrained premium UI, responsive product workspace, explicit approval before outreach, and no fabricated activity or analytics.

## Rebuild

The project is intentionally reset. Frontend, API, authentication, persistence, email delivery, scheduling, and reply handling will be added in deliberate stages.
